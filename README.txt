Task 04: Tic-Tac-Toe. SkillCraft Technology - Mini Web Projects

Task_03_Todo_App
- Add tasks with optional due date and time
- Organize by Personal, Work, Study, Other
- Mark tasks complete, edit, delete
- Filter all / to-do / completed and by list
- Progress statistics
- Uses browser localStorage to retain tasks on the same browser

Task_04_Tic_Tac_Toe
- Play against the computer or a second player
- Tracks game state and wins
- Detects wins and draws
- Computer makes strategic moves (win, block, center, corners)
- Restart rounds and reset scores

How to run either app:
1. Open its folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. No package installation is required.
